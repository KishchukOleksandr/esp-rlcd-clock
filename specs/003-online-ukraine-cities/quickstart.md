# Quickstart & Validation Guide: Розширений онлайн-вибір будь-якого міста України

**Feature**: `003-online-ukraine-cities`  
**Target Board**: Waveshare ESP32-C6-DEV-KIT-N8 (`esp32c6`, 8MB Flash, 512KB SRAM)  
**Contracts**: [http-api.md](file:///d:/Pets/esp-rlcd-clock/specs/003-online-ukraine-cities/contracts/http-api.md) | **Data Model**: [data-model.md](file:///d:/Pets/esp-rlcd-clock/specs/003-online-ukraine-cities/data-model.md)

## 1. Передумови та збірка прошивки

```powershell
# Активувати середовище ESP-IDF v6.1 (якщо ще не активовано)
idf.py set-target esp32c6
idf.py build
```

Переконайтеся, що збірка проходить із **нулем попереджень компілятора** (`-Wall -Wextra`) у всіх компонентах проєкту (включно з новим компонентом `geo_search`).

Прошивка та запуск монітора:
```powershell
idf.py -p COMx flash monitor
```

## 2. Запуск модульних тестів (Unity)

Модульні тести `test/unit/test_geo_search.c` перевіряють валідацію UTF-8 запитів, percent-encoding кирилиці, безпечне UTF-8 обрізання до 64 байтів та парсер JSON Open-Meteo (включно з фільтрацією `country_code == "UA"`).

Запуск у межах тестової збірки ESP-IDF (згідно з конфігурацією `test/unit/`):
```powershell
idf.py -p COMx flash monitor
```
Очікуваний результат: усі тести `test_geo_search.c`, `test_config_store.c`, `test_http_validation.c` і `test_wifi_fsm.c` проходять без помилок (`0 Failures`).

## 3. Сценарії наскрізної перевірки на платі

### Сценарій A — Офлайн-режим (точка доступу без Wi-Fi / роутер без Інтернету) (`US3`, `FR-002`, `FR-007`, `SC-004`)
1. Підключіться до SoftAP пристрою `ESP Weather Clock` і відкрийте `http://192.168.4.1`.
2. Перевірте `GET /api/status`: поле `internet.available` має бути `false`.
3. У блоці «Місце знаходження» відображається статус офлайн-режиму; поле та кнопка онлайн-пошуку неактивні.
4. Оберіть місто зі вбудованого офлайн-списку (наприклад, `Львів`) і натисніть **«Зберегти місце знаходження»** → збереження успішне.
5. *(Опціонально)* Підключіть ESP32 до роутера без доступу в Інтернет: після підключення `sta.connected === true`, але `internet.checked === true` і `internet.available === false`.

### Сценарій B — Онлайн-пошук невеликого міста/селища України (`US1`, `FR-001`, `FR-005`, `SC-001`, `SC-002`)
1. Підключіть ESP32 до домашньої Wi-Fi мережі з доступом до Інтернету та відкрийте сторінку налаштувань за локальною IP-адресою або `http://weather-clock.local`.
2. Перевірте `GET /api/status`: `internet.available === true`, `internet.checked === true`.
3. У полі онлайн-пошуку введіть назву населеного пункту, якого немає у вбудованому списку (наприклад, `Чортків` або `Кам'янець-Подільський`), і натисніть **«Пошук»** (або `Enter`).
4. Переконайтеся, що результати з'являються менш ніж за 5 секунд, усі належать Україні й містять область.
5. Клікніть потрібний результат: у поле назви підставляється **лише назва населеного пункту**, у поля широти/довготи — його координати.
6. Натисніть **«Зберегти місце знаходження»** → з'являється підтвердження збереження, Wi-Fi з'єднання не переривається.
7. Перезавантажте плату (`RESET`) і повторно відкрийте сторінку → збережене місто та координати відновилися (`SC-005`).

### Сценарій C — Однойменні населені пункти (`US2`, `FR-003`, `FR-004`, `SC-003`)
1. Введіть у поле онлайн-пошуку `Вишневе` (або `Олександрівка`) і натисніть **«Пошук»**.
2. Переконайтеся, що у списку результатів поруч із назвою відображається область (і район, якщо доступний), а закордонні населені пункти відсутні.
3. Оберіть варіант із конкретної області → підставляються координати саме цієї області, а в поле назви підставляється `Вишневе`.

### Сценарій D — Негативні та граничні сценарії (`FR-008`, `FR-011`)
1. Введіть 1 символ (наприклад, `К`) і натисніть **«Пошук»** → локальна підказка без запиту на сервер.
2. Введіть `Варшава` або `Абракадабра123` і натисніть **«Пошук»** → повідомлення «Населених пунктів України не знайдено», збережені налаштування не змінюються.
3. Перевірте лог серійного порту (`ESP_LOGI` / `app_core_log_diagnostics()`): відсутні витоки пам'яті (`free_heap_bytes` повертається до базового рівня після завершення пошуку) та достатній запас стеку (`uxTaskGetStackHighWaterMark`).
